The game

Open World is a free, single-player, in-browser tycoon game set on the real Earth, at true 1:1 scale, built from OpenStreetMap data. It is provided at no cost.

Play money only

There is no way to spend real money in the game, nothing can be bought for real money, and nothing can be cashed out — the game is not gambling. No one is authorized to sell in-game money or assets; if someone offers to, it is a scam.
